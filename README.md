# 🎮 Thyrops Live

Portal oficial das lives com agenda, comandos do chat, histórico de jogos e votações da comunidade.

## 📑 O que você encontra em cada aba

* **Início (`index.html`):** Contagem regressiva para a próxima live e um resumo geral das platinas.
* **Placar (`placar.html`):** Estatísticas de jogos platinados e zerados por console, total de horas jogadas, barra de progresso das platinas feitas em live e a votação para escolher os próximos jogos.
* **Jogos (`jogos.html`):** Catálogo completo dos jogos do RetroAchievements com status (platinado, zerado ou em andamento), porcentagem de progresso, tempo de jogo e indicação de quais foram feitos em live — com barra de busca e filtros.
* **Guia (`guia.html`):** Destaque para o último short do *Guia de Conquistas* e a gameplay mais recente, além das playlists completas de guias e transmissões para assistir direto no site.
* **Agenda (`agenda.html`):** Programação semanal das lives, contagem regressiva e conversão automática de horário para o fuso local de quem acessa.
* **Vozes (`vozes.html`):** Catálogo completo de comandos de voz separados por categorias (Animes, Games, Séries, Filmes, etc.) com prévia de áudio para testar antes de usar no chat.
* **Troca Voz (`trocavoz.html`):** Lista de comandos do chat para alterar a voz do streamer ao vivo durante a transmissão.
* **Memes (`memes.html`):** Biblioteca de áudios e vídeos de memes para ativar no chat, com botão para ouvir/assistir e copiar o comando rapidamente.
